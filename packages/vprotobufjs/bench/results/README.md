# Historical protobuf measurements

The October 30 reports measured the previous upstream-derived runtime with a
same-process harness. They do not describe the independent application runtime
and no current performance claim is based on them. Their original data remains
in repository history.

Use the [current process-isolated reports](../application-results/README.md).
Both `bench/compare.cjs` and `bench/application.cjs` now run that harness.
