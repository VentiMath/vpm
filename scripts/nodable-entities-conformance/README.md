# Nodable entity conformance

Private locked controls for `vnodable-entities`: @nodable/entities **3.1.0**,
fast-xml-parser **5.11.2**, fast-xml-builder **1.3.1**, checked October 30, 2026.
Storage **8.4.0** comes from the adjacent retry-request fixture. These upstream
packages and retained evidence are excluded from runtime archives.

```sh
npm --prefix scripts/nodable-entities-conformance ci --ignore-scripts --no-audit --no-fund
node scripts/nodable-entities-conformance/run.cjs --upstream
node scripts/nodable-entities-conformance/run.cjs
node scripts/nodable-entities-conformance/regressions.cjs
node scripts/nodable-entities-conformance/callers.cjs --upstream
node scripts/nodable-entities-conformance/callers.cjs
node scripts/nodable-entities-conformance/bundles.cjs
```

Repeat with `bun`. Root package tests include retained cases and independent
checks; the integration gate runs actual callers. CI runs unchanged upstream
controls, paired discriminators and browser bundle checks on both runtimes.

## Source, tables and adaptations

`upstream/` retains the monorepo's license and Entity package source, declarations,
docs and three test files at commit
`b89ecb0d419969e2989b74c5304bc9b66931727e`. Files have `.txt` extensions and
normalized trailing EOF whitespace. SHA-256 checks protect every snapshot; the
runner also requires every installed source file to match the pinned source.

The runner supplies assert-backed Jest-style matchers and the original Node
assert module, removes imports in memory and runs all **246 cases**: 150 decoder,
37 numeric-reference and 59 encoder tests. The unchanged upstream control passes
all cases. VPM changes three guarded expected strings in the encoder tests:
ASCII period, slash, and `!@#` use names from the explicitly selected full map.
The original snapshots remain unchanged; no cases are skipped.

`generate-data.cjs` regenerates all 15 category exports and the combined table.
Four mappings are corrected against the HTML Standard: `ocirc`, `boxDl`, `boxdL`
and `af`. All other names/values, including 23 nonstandard aliases, are retained.
The combined 932-name table is not a complete HTML5 table. Focused tests compare
every category/key with retained upstream data plus these explicit corrections.

Seventeen focused tests cover all 1,114,112 Unicode code points under both XML
versions, strict numeric parsing, long references, own-key registration, failed
registration atomicity, hook contracts/reentrancy, private counters, quota
semantics, immutable tables, encoder cache isolation, CJS/ESM exports and
single-read option getters. An independent longest-prefix reference checks
10,000 seeded encoder strings. `regressions.cjs` records 19 paired differences,
including failed-registration limit bypass, state reset, malformed references,
noncharacters, encoder omissions and all four mapping corrections.

## Actual callers

The parser's published CJS bundle embeds its helpers. `callers.cjs` copies actual
parser/builder sources to a temporary directory, replaces only the entity import
and parser's builder re-export, and counts calls through a shared adapter. Exact
import counts and package versions guard the edits. VPM exports are loaded
through CommonJS so the integration gate's proxies observe use.

Twelve differential parser cases cover ordinary/numeric/HTML entities, a custom
HTML map, attributes, unknown references, disabled processing, DTD registration,
blocked markup, allowed tags, count/length limits and XML 1.1. Additional checks
record intentional malformed/noncharacter differences, a shared decoder's version
reset between documents, cumulative limits across text nodes, reset after a
failed parse, and parser.addEntity().

Storage's actual `TransferManager.uploadFileInChunks` completes two uploads with
string/Buffer XML responses. Six mocked requests validate initiation, part bodies,
MD5 hashes and completion XML. Escaped object keys are decoded in both responses.
Each control/VPM run records 18 constructions, 27 decode calls, 20 resets, three
input registrations and two XML-version updates. Storage accounts for two
constructions/resets and both escaped-key checks. Network transport is mocked;
XML parsing and SDK upload code run. Caller-specific DTD and transport policies
remain outside this package.

The parser passes `Infinity` for unlimited counts and sometimes forwards its
HTML entity map as `numericAllowed`; both forms are explicitly supported.
`bundles.cjs` builds and executes browser bundles through Bun, checking that
XML-only and encoder-only outputs omit unrelated tables and that the full-table
bundle retains corrected names. Generated byte counts depend on bundler version.
